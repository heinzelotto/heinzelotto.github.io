The rubric behind the numbers

The flagship map on this site extracts the argument of the book If Anyone Builds It, Everyone Dies (Yudkowsky and Soares, 2025). Every claim on that map carries a number, and the book states almost none. So where do the numbers come from?

They come from the authors' own confidence language, read through a fixed table: "repeated categorical assertion" is 0.93, a flat unhedged assertion is 0.90, "by default" and "our best guess" are 0.85, "we expect" is 0.75, "could well" is 0.70. The table was written down before any number was assigned, and no number was moved afterwards to make the map come out better. This page is that table, the protocol that applied it, and the honest account of what it can and cannot support.

Why it matters: the map's overlay marks places where the solved value and the authors' own stated confidence disagree. If the mapmaker had picked the numbers, such a mark would only say "the mapmaker disagrees with the book". Because the numbers are the authors' words run through a table fixed in advance, the mark says something stronger: the book's own confidences do not add up to the book's own conclusion there. That claim is worth only as much as the pre-registration behind it, which is why the pre-registration is on this page.

For what happens to the numbers after they are assigned (the probability model, the solve, what has been proved about it), see the mathematics behind ArgMap. For writing your own maps, see the authoring tutorial.

1. The protocol

The map-wide pass ran on 2026-07-19 as a pre-registered experiment. Its rules, as recorded that day:

  1. The rubric first, blind. Each extension to the table (section 2) was derived by an independent agent from the relevant source pages, with no access to any solve.
  2. Five independent elicitors, one per region. Each was given only the fixed rubric and their region's text with every number stripped to ?. No elicitor saw another's region.
  3. Every number registered before the region was solved once. One honest solve per region, after the numbers were fixed.
  4. Nothing moved afterwards. Where the solve disagreed with the authors' stated confidence, the disagreement was recorded as a finding, not repaired by editing a number.
  5. Provenance on every value. A rubric-derived number carries the ? marker in the map source. A bare number is reserved for figures the authors state as figures, and outside quoted insider odds the book states none.
  6. The driving quote travels with the number. Each re-elicited node carries the sentence it was read from, either as an attributed quote line under the node or in the trailing comment that names its rubric class.

Rule 4 is the one that does the work. A rubric with a repair step is a rubric that fits the conclusion; this one has none, and the map still carries the gaps that produced.

2. The tables

Class names are the ones used in the map's own trailing comments, so a number on the map can be traced back to the row that produced it. A trailer reading # R-COARSE C2: ... names this table.

2.1 Statement registers

The base table, derived from the chapter 5 supplement pages before the pilot region was authored (2026-07-17) and unchanged since:

Class The source's language Value
C1 "overwhelmingly", "vanishingly" 0.97
C2 "extremely unlikely", "highly doubt" (title register) 0.93
C7 flat unhedged assertion 0.90
C3 "quite unlikely", "our top guess" 0.85
C4 "probably not" 0.75
C5 "seems unlikely" 0.70

The classes are symmetric: a class states how firmly the authors hold a proposition, whichever way the proposition points.

2.2 R-STEP: the language of a reasoning step

A reasoning link carries its own number, and it is read from the language attached to the step, not to the conclusion. The lookup registered before the campaign:

Row The step's language Value
S1 title register 0.93
S2 flat entailment 0.90
S3 the chess register ("you cannot predict its moves, but you can predict that it wins") 0.90
S4 instrumental convergence 0.90
S5 grown, therefore opaque 0.90
S6 "by default" 0.85
S7 "our best guess" 0.85
S8 "we expect" 0.75
S9 "could well" 0.70

Two tables rather than one, kept separate on purpose even where the values coincide: how firmly an author holds a claim and how strongly they present a step are different measurements, and merging the tables would hide the difference.

2.3 R-NORM: deontic language

The policy half of the book asserts norms ("no one may build this", "it must be shut down") rather than predictions, so the deontic classes were registered separately:

Row The language Value
N1 categorical, repeated, with the authors' own anti-hyperbole note 0.93
N2 unhedged deontic assertion 0.90
N3 the "insane gamble" intensifier 0.93
N4 hedged institutional claim 0.75
N5 exploratory 0.70

2.4 R-OPP: the opponent's material

An objection on the map is a claim the authors do not hold, so its number is the authors' credence in it, read from how they treat it:

Row How the authors treat the opposing premise Value
P-FACT accepted as fact 0.90
P-GRANT granted for the sake of argument 0.75
P-CONTEST contested outright 1 minus the class of the denial

P-CONTEST is the mirror rule: a premise the authors deny flatly (C7, 0.90) enters at 0.10, one they deny with a hedge enters higher. It never enters at 0, because "we do not think so" is weaker than "impossible".

2.5 The procedural rules

Three registered with the tables, plus the standing authoring convention the pass worked under:

  • R-FALLBACK, silence. Where the book and its supplement pages give no confidence language, the node keeps a role-based default, keeps its ?, and is listed in the pass log as residual mapmaker voice. Never invent an author number. One inheritance exception is licensed: a step that restates a sentence the authors do assert takes that sentence's class, because the assertion is the step's own language.
  • R-COARSE, summary lines. A coarse summary line takes its number from the book's own one-sentence formulation of the step. The book's title sentence is at least C7, and C2 where the authors' own disclaimer is attached to the summary sentence itself. A mismatch between a summary and the finer steps under it after solving is a readout, not an inconsistency to tune.
  • R-COMPOSE, stacked hedges. For "we mostly expect that probably X", take the outermost hedge's class. Where two readings are genuinely defensible, record both in the log and author the weaker.
  • The residual rule. A statement's own number should carry evidence that is not already somewhere else on the map, because counting the same consideration twice is exactly what the accumulation machinery assumes away.

2.6 The pair extension (2026-08-23)

The book states neither points nor intervals: it states registers. Since 2026-08-23 a statement's authored credence is a pair, a floor for the claim and a floor against it, with the gap between them the mass the authors leave open. The register table gained a pair column, registered before any node was touched, and each two-sided pair's midpoint is the class point above. The two one-sided rows leave nothing against, so their midpoint sits higher than their point: 0.95 for the deontic row, 0.975 for the categorical one.

Register (class) Point Pair
repeated categorical, anti-hyperbole (C1) 0.97 0.95?/0?
categorical deontic, "insane gamble" (N1, N3) 0.93 0.9?/0?
title register (C2) 0.93 0.88?/0.02?
flat unhedged assertion (C7, P-FACT) 0.90 0.85?/0.05?
"by default", "our best guess" (C3) 0.85 0.75?/0.05?
"we expect", a granted point (C4, P-GRANT) 0.75 0.6?/0.1?
"could well" (C5) 0.70 0.55?/0.15?
explicit refusal, "nobody knows" 0.50 0.1?/0.1? and a gloss sentence
an objection denied at class X (P-CONTEST) 1 minus X the mirror of X's pair

The width does work of its own. Besides recording the mass the authors leave open, since 2026-09-08 it sets how firmly the solve holds the number when a reader drags it: a narrow pair takes many contrary flips to move, a wide one gives easily. On this map the middle pin is worth about 18 flips of evidence, which is less than a typical mechanism step: under a reader's what-if the authors' assertions give before their mechanisms do.

3. Where a number can land

Three slots, and they are not interchangeable:

  • A pin on a claim nothing on the map argues for. These are the map's interface to everything outside it, and they constrain the solve.
  • A strength on a reasoning link, from R-STEP. Also constrains the solve.
  • A check on a claim the map does argue for, written # check: 0.88..0.98. This is the authors' own all-things-considered confidence, displayed against the computed value and never constraining the solve. It is how the map can say "the argument delivers 0.83, and the authors state 0.88 to 0.98" without either silently overwriting the other.

The separation is what makes an audit possible. A claim the book argues for gets its number computed from the argument, and the authors' own stated confidence in it stands beside that number as an independent reading.

4. The badge: how a disagreement is measured

The solved value of a claim is compared with its check interval. The badge is the signed distance from the computed value to that interval, zero anywhere inside it. Past 0.10 the map marks the claim, and that mark is the whole point of the exercise: it says the authors' own numbers, run through the authors' own steps, land more than ten points away from the authors' own stated confidence.

Two facts have to hold before a badge means that, and both are checkable:

  1. The numbers are the authors', assigned in advance. Sections 1 and 2.
  2. The badge is not an artifact of how the map is solved. This one was false for a while, and the project found it and said so. Until 2026-09-08 the deployed solve used a uniform counting reference, under which asserting a conditional pulled its antecedent down. On the map as it stood on 2026-09-06, four of the five badges past 0.10 were partly that pull rather than the book, which was measured, recorded, and fixed by changing the reference (D159, D161), with the map text untouched. The mathematics page keeps the retired reference as a dated section so the old numbers stay reproducible.

Where the flagship stands today. Measured 2026-09-11 with solve_map.py at the shipped reference, on the map as deployed: no claim badges past 0.10. The largest single gap is @everyone-dies, the book's title claim, computed at 0.827 against a stated 0.88 to 0.98, short by 0.053. The policy conclusion @shutdown computes at 0.994 against a stated 0.90 to 1.00. Sixty claims on the map carry a check for the comparison to run against.

That is a strong result for the book, and it is worth stating what it is not. It is not the map agreeing that the book is right. It says the authors' stated confidences are mutually consistent under this model: their premises deliver their conclusions to within the badge threshold, and the two headline conclusions come out at or above what the authors claim for them. A perfectly coherent argument can still rest on false premises, and this instrument has no view on that.

5. What the audit found, and what happened to each finding

The 2026-07-19 pass ended with badges standing, and the rule was to keep them rather than repair them. Their history since is the honest test of that rule:

  • Steps outrun summaries, across the whole map. Where the authors argue flat, several convergent unhedged assertions compound to near-certainty while the authors' own summary of that section stays hedged. Under the model that is a finding about the book's prose, not an error, and those gaps are still on the map: the ten largest today sit between 0.040 and 0.053, and eight of the ten are claims the argument delivers more firmly than the authors state them (measured 2026-09-11).
  • The evolution analogy under-delivered. The pass computed @evo-analogy at 0.449 against a stated 0.85: the authors grant the disanalogy so thoroughly that their own concessions left the analogy standing at half their stated confidence. It stayed on the map as a badge for seven weeks. It closed on 2026-09-08, and the way it closed is the point: nobody moved a number. A later pass found that the chapter's own case for the analogy had never been mapped, mapped it, and the claim rose to 0.858 (measured 2026-09-11), inside its interval. A badge is a question about the map or the book, and the licensed answers are "map the passage that was missed" and "leave it standing", never "adjust the number".
  • The top line's residual. The pilot region reproduced the authors' conclusion to within 0.07 and localised what was missing to one named conjunct and one deliberately excluded line, rather than leaving it a mystery. The exclusion was itself pre-registered: adding the line after seeing the solve would have broken rule 4.

6. Honest limits

  • A verbal-to-probability table is a modeling decision. The table is fixed and public, which makes the numbers auditable. It does not make them correct. A different defensible table would move most of them, and the project claims only the first thing.
  • Reading a register as a credence has a known cost. An author's stated confidence in a claim may already discount what they believe about its consequences, so feeding it back in as evidence can apply the same reasoning twice. There is no operational alternative, because the text never gives the undiscounted figure. The size of the effect was measured and is small at these widths, and the compensation is to show the interval rather than present a midpoint as the author's number.
  • The classification is judgment, sometimes. A sentence can sit between two rows of the table, and by rule 2 each region's classes were read by a single elicitor, with no second reader over the class itself. Where a register was borderline, one person's ear settled it. The 2026-07-19 pass log records two numbers a second agent read differently, @mis-ext and @precedented, both settled by authoring the weaker of the two readings. The one label on this map that did get a systematic second pass is a different one, the kind of step each reasoning link makes: on 2026-09-08 two blind passes over all 348 links disagreed on 68 of them, and a third reader settled those.
  • This rubric is for one book. It was derived from the confidence language of one text in one genre. A spoken debate needed its own table (the register for speech is looser than for edited prose), and maps written since carry their rubric inside the map file itself.
  • The solve is not a truth oracle. It says what a set of authored numbers jointly implies, and has no view on whether they are right.

7. The record

The dated registration entries, one per pass, live in the project's authoring log, which is not yet public along with the rest of the working repository. This page is the distillate of those entries and carries every rule they registered.

What you can check without the repository is the map itself. Open any claim on the flagship map and its detail panel shows the authored number, the computed one, and the source passage the number was read from. The trailing comment on a node in the Editor pane names the rubric class that produced its value, so a number on the map traces to a row in section 2, and the quote lines under a node give the sentence it was read from, with its locator in the book.

Numbers on this page were measured on 2026-09-11 against the deployed solve, and each says so where it appears.
